初试FastAPI

2026/4/25 FastAPI

路由

路由是url地址和函数之间的映射关系
新建python的FastAPI项目,在main.py中添加以下内容：

from fastapi import FastAPI
//创建FastAPI应用实例
app = FastAPI()

//定义一个根路由，返回一个简单的JSON响应
//这里的@app.get("/")是一个装饰器，表示这个函数是处理GET请求的，并且路径是"/"，也就是根路径。当访问这个路径时，异步函数read_root会被调用，返回一个JSON对象{"Hello": "World"}。
@app.get("/")
//相当于@RequestMapping("/")，默认是GET请求
async def read_root():
    return {"Hello": "World"}

路由参数

路由参数分为三种：路径参数、查询参数、请求体参数

  • 路径参数：直接在路径中定义参数，是url的一部分，如
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}

另外，FastAPI还有Path注解可以对路径参数进行验证和设置默认值，如：

@app.get("/items/{item_id}")
async def read_item(item_id: int = Path(..., title="The ID of the item to get", ge=1)):
    return {"item_id": item_id}

这里的Path(…)表示这个参数是必填的，title是参数的描述，ge=1表示这个参数必须大于等于1。

  • 查询参数：在url中以?key=value的形式传递参数，如
@app.get("/items/")
async def read_items(
    skip: int = query(0, title="Number of items to skip", ge=0),
    limit: int = 10):
    return {"skip": skip, "limit": limit}

这里的注解query(0, title=”Number of items to skip”, ge=0)表示这个参数是可选的，默认值是0，title是参数的描述，ge=0表示这个参数必须大于等于0。

  • 请求体参数：通过请求体传递参数，通常是POST、PUT、PATCH等请求，如
    根据HTTP协议，一个请求分为三部分：请求行、请求头、请求体。
    请求行：包含请求方法（GET、POST等）、请求路径和HTTP版本。
    请求头：包含一些元信息，如Content-Type、Authorization等。
    请求体：包含实际的数据，如JSON、表单数据等。
from pydantic import BaseModel
class Item(BaseModel):
    name: str
    description: str = None

@app.post("/items/")
async def create_item(item: Item):
    return item

这里的Item是一个Pydantic模型，定义了请求体的结构。当发送一个POST请求到/items/路径时，FastAPI会自动将请求体中的JSON数据解析成一个Item对象，并传递给create_item函数。

同样的，FastAPI还有Body注解可以对请求体参数进行验证和设置默认值，如：

@app.post("/items/")
async def create_item(item: Item = Body(..., title="The item to create")):
    return item

这里的Body(…)表示这个参数是必填的，title是参数的描述。

另外，pydantic中还有Field注解可以对模型字段进行验证和设置默认值，如：

class Item(BaseModel):
    name: str = Field(..., title="The name of the item", max_length=100)
    description: str = Field(None, title="The description of the item", max_length=255)

这里的Field(…)表示这个字段是必填的，title是字段的描述，max_length是字段的最大长度。

响应类型

默认情况下，FastAPI会将返回的Python对象转换成JSON格式的响应，省去了手动序列化的步骤，而且支持多种响应类型，如JSON、HTML、文件等。

指定响应类型的方法有两种：

  • 在装饰器中指定，如HTMLResponse、FileResponse等，如
from fastapi.responses import HTMLResponse
@app.get("/html/", response_class=HTMLResponse)
async def get_html():
    html_content = "<html><body><h1>Hello, World!</h1></body></html>"
    return HTMLResponse(content=html_content, status_code=200)
  • 在函数中返回特定的响应对象，如JSONResponse、FileResponse等，如
from fastapi.responses import fileResponse
@app.get("/file/")
async def get_file():
    file_path = "path/to/your/file.txt"
    return FileResponse(path=file_path, filename="file.txt", media_type="text/plain")

这里的FileResponse会将指定路径的文件作为响应返回，filename是下载时的文件名，media_type是文件的MIME类型。

这两种方法各有优缺点，第一种方法更简洁，严格，适合简单的响应类型；第二种方法更灵活，适合需要自定义响应内容或状态码的情况。

还有一种方法可以自定义响应类型，就是用基于Pydantic的模型来定义响应结构，如：

from pydantic import BaseModel
class ItemResponse(BaseModel):
    name: str
    description: str = None

@app.get("/items/{item_id}", response_model=ItemResponse)
async def read_item(item_id: int):
    item = get_item_from_database(item_id)
    return ItemResponse(name=item.name, description=item.description)

异常处理

FastAPI提供了HTTPException类来处理HTTP异常，可以在路由函数中抛出这个异常来返回特定的错误响应，如：

from fastapi import HTTPException
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    item = get_item_from_database(item_id)
    if item is None:
        raise HTTPException(status_code=404, detail="Item not found")
    return item

这里的HTTPException(status_code=404, detail=”Item not found”)表示当item为None时，抛出一个404 Not Found的错误响应，detail是错误的详细信息.
