Vibe coding基础-1

2026/6/7 Vibe coding

任务目标

跟随datawhale的Vibe coding教程完成一个个人数字分身.

Prompt基础:具体比抽象更有用

从一个模板开始,填空完成prompt

我想做一个个人主页，上面有一个数字分身聊天区。

【关于我】
- 名字：______
- 一句话介绍：______
- 我现在主要在做：______
- 我的兴趣：______
- 我一个比较有记忆点的特点：______

【这个主页给谁看】
- 主要访客：______

【页面里至少要有】
- 头像
- 名字和一句话介绍
- 一个简单的个人信息展示区
- 一个可以提问的数字分身聊天区

【数字分身需要知道】
- 我的职业或身份：______
- 我最近在做的事：______
- 我擅长或关心的方向：______
- 别人最可能问我的 3 个问题：______

【风格要求】
- 我希望整体感觉是：______
- 我更偏好的颜色：______
- 是否要适配手机：是
- 其他要求：______

请先帮我生成一个第一版原型。
要求：
1. 先保证结构清楚、能用
2. 不要过度复杂
3. 先做出一个可预览的版本

这里填写时注意,尽量不要使用形容词,而是使用具体的时间或动作来形容自己.
比如我是喜欢很多东西,可以写成具体的我喜欢表编程,音乐和美术.提示词越具体,ai越容易理解.
另外开始时记得开启计划模式(plan model)

做出第一版并微调

把上面的prompt交给agent编程工具,让他给你做出第一版,此时大概率是不太符合我们的要求的,所以要进行微调.微调的流程一般是:看到产品->指出一个最明显问题->
写prompt让ai修改->再次预览->是否满意?满意就结束:否则继续循环

第一轮:修复明显错误

prompt可以按照这个模板写:

先不要大改整个页面.
先改一个最明显的问题:
xxx

这一轮只修改这个问题,不要修改整体风格和其他内容.

这里注意每轮最好只让ai专注于一个问题,不要一次性让ai修复太多问题.

第二轮:调整内容和风格

这一轮开始优化产品,处理比如风格太花或太素,个人信息层次不清楚的问题.
prompt参考:

现在结构已经基本对了。
接下来我只想调整整体风格：
- 让页面更简约、清爽
- 主色调改成深蓝和白色
- 不要增加新的复杂模块
请只做风格层面的修改。

这里注意要把改动边界说清楚,比如请只做风格层面的修改.防止修一个bug,结果产生了好几个bug的概率.

第三轮:做小幅度细化

这一轮就可以开始抠细节了,处理那些”不是问题,但修改后会更顺眼的细节”,比如按钮的圆角,面板之间的距离.

页面整体已经接近我想要的效果了。
现在请只做小幅细化：
- 把聊天框的引导语改得更自然一点
- 让头像和简介区的间距更舒服
- 不要新增模块，也不要重做布局

总的来说,要注意两点:

  1. 每次只让ai完成一个任务
  2. 限制每次改动的范围

第一轮验收与优化

很多人会陷入一个死循环里:既然都已经做出来了,再加一点,再改一点…
最后第一章永远无法结束了,所以我们要明确验收标准.

尝试制订验收清单

页面能正常打开
我的名字和一句话介绍清楚显示
页面看起来已经像“我的个人主页”而不是完全空白模板
聊天入口存在，并且能完成基础提问
手机端至少可以正常浏览

如果以上标准都可以通过,就可以开始第二轮开发了.第一轮的目标是先做出一个能用的版本,不要求完美,只要满足基本功能和结构就行了.

记录下一轮优化清单

第一轮跑出来后,你一定可以注意到有些可以优化的地方,可以分为以下四类:

  1. 界面问题:颜色不好看,排版不顺,ai味太重了之类的
  2. 内容问题:自我介绍太空,联系信息不完整
  3. 产品问题:回答太机械,没有接入真正的llm
  4. 体验问题:用户不知道按什么按钮,链接鼠标移动上去没有反馈

可以根据需要确定需求优先级,在后面的部分进行开发.

总结

  1. 用prompt明确任务目标,缩小工作范围
  2. 在开始任务前使用计划模式
  3. 每轮只让ai专注一个问题,同时明确任务边界
