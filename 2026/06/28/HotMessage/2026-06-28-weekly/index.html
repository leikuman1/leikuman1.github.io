本周摘要

统计周期：2026-06-21 20:03:26 至 2026-06-28 20:03:26（Asia/Shanghai）

本周 AI 与大模型的主线是更强模型、更多代理化工作流和更垂直的算力平台同时推进，OpenAI、Anthropic 均把发布重点放在模型能力与安全治理的平衡上。宏观与金融方面，美国消费、GDP、银行压力测试和中美欧监管协调继续影响市场预期，中国工业企业利润数据也显示制造业利润修复仍是观察重点。政治方向，美国发布国家韧性战略并继续围绕北约、维和和地区安全议题展开政策动作。科技方向，量子、后量子密码、操作系统开发链路和数据中心基础设施成为本周较高信号的更新。

AI 与大模型

1. OpenAI 开始 GPT-5.6 Sol 有限预览

  • 摘要：OpenAI 发布 GPT-5.6 系列预览，包含 Sol、Terra、Luna 三个层级，先向可信合作伙伴开放 API 与 Codex 使用，并配套系统卡披露安全评估。
  • 重要性：这是前沿模型发布从单纯能力升级转向“能力、分层访问、安全评估、政府沟通”同步推进的典型案例。
  • 时间：2026-06-26（原始发布时间）
  • 信息来源：OpenAI 发布说明、GPT-5.6 Preview System Card

2. OpenAI 与 Broadcom 推出面向 LLM 推理的 Jalapeño 芯片

  • 摘要：OpenAI 与 Broadcom 公布 Jalapeño 推理加速器，称其从设计到量产用时 9 个月，将按多代平台和数据中心合作伙伴进行吉瓦级部署。
  • 重要性：大模型公司继续向芯片和基础设施纵深整合，推理成本、能效和供应链控制将成为模型竞争的关键变量。
  • 时间：2026-06-24（原始发布时间）
  • 信息来源：OpenAI 官方公告

3. Anthropic 发布 Claude Tag，把 Claude 接入 Slack 团队协作

  • 摘要：Anthropic 推出 Claude Tag，允许企业和团队用户在 Slack 频道中 @Claude 分派任务、读取授权上下文并计划后续工作。
  • 重要性：团队协作场景正在从“个人助手”转向“频道内可被委派的代理”，AI 工具的组织嵌入程度进一步提高。
  • 时间：2026-06-23（原始发布时间）
  • 信息来源：Anthropic 官方公告

4. OpenAI 发布关于代理改变工作的经济研究

  • 摘要：OpenAI 发布经济研究文章，强调代理式 AI 将知识工作从短交互推进到可委派的长周期任务，并以 Codex 在组织内部的使用变化作为观察对象。

金融

1. 中国 1—5 月规模以上工业企业利润同比增长 18.8%

  • 摘要：国家统计局公布，2026 年 1—5 月全国规模以上工业企业实现利润总额 31439.6 亿元，同比增长 18.8%，其中制造业利润增长 20.0%。
  • 重要性：工业利润是观察中国企业盈利修复、制造业景气度和政策传导效果的重要指标。
  • 时间：2026-06-27 09:30（原始发布时间）
  • 信息来源：国家统计局数据发布

2. 美联储年度压力测试显示大型银行能承受严重衰退情景

  • 摘要：美联储称大型银行在本年度压力测试中可承受超过 7080 亿美元的假设贷款损失，资本率总体下降 1.6 个百分点但仍高于最低要求。
  • 重要性：压力测试结果影响市场对美国银行体系韧性、信贷供给和监管资本要求的判断。
  • 时间：2026-06-24 16:00 EDT（原始发布时间）
  • 信息来源：Federal Reserve 官方新闻稿

3. 美国 5 月 PCE 与一季度 GDP 修订同时强化通胀观察

  • 摘要：BEA 公布 5 月 PCE 价格指数环比上涨 0.4%、核心 PCE 环比上涨 0.3%；同日公布的一季度 GDP 第三次估算为年化增长 2.1%。
  • 重要性：增长韧性与价格压力并存，会影响市场对美联储政策路径和资产定价的预期。
  • 时间：2026-06-25（原始发布时间）
  • 信息来源：BEA 5 月个人收入与支出、BEA 一季度 GDP 第三次估算

4. SEC 与 CFTC 就投资组合保证金框架协调征求意见

  • 摘要：SEC 与 CFTC 联合征求公众意见，研究证券、期货、掉期等市场的投资组合保证金框架协调问题，意见期为联邦公报发布后 60 天。
  • 重要性：跨监管框架的保证金协调可能影响清算、流动性、客户保护和衍生品市场效率。
  • 时间：2026-06-26（原始发布时间）
  • 信息来源：SEC 官方新闻稿

5. BIS 年度经济报告警示全球经济压力点

  • 摘要：国际清算银行在 2026 年年度经济报告中指出，金融体系脆弱性、公共财政压力和供应冲击仍对全球增长构成风险，并强调价格稳定和金融稳定。
  • 重要性：BIS 报告通常影响央行、监管者和市场对全球金融周期、财政金融联动风险的讨论。
  • 时间：2026-06-28（原始发布时间）
  • 信息来源：BIS 年度经济报告、BIS 新闻稿
