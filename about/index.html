关于我

我主要关注 后端工程 + AI 应用落地，目前博客用来沉淀项目复盘、技术学习和面试表达。这里不会追求文章数量，而是优先把能体现工程判断、问题拆解和持续学习能力的内容整理清楚。

技术方向

  • 后端开发：Java / Python / Go，关注接口设计、异步消息、缓存、数据库和并发模型。
  • AI 应用：RAG、Agent、工具调用、工作流编排和大模型应用工程化。
  • 工程实践：Git 协作、错误处理、链路补偿、可维护代码结构和项目复盘。

重点内容

  • 项目总览：后端与 AI 应用实践
  • 高并发秒杀系统复盘
  • RAG/Agent 应用工程化复盘
  • Go 并发编程
  • Git 基本操作详解

我希望博客体现什么

  1. 能把一个技术点讲清楚，而不是只堆概念。
  2. 能说明方案取舍，例如为什么用 Redis + Lua、为什么用 MQ 削峰、为什么 RAG 需要引用来源。
  3. 能沉淀踩坑和边界条件，例如消息失败补偿、缓存一致性、并发控制和 Agent 可控性。
  4. 能持续迭代，旧草稿会先归档隐藏，高质量内容再公开展示。
