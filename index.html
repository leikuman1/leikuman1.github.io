前缀树

题目名：前缀树

1. 题型标签

字符串，前缀，字典树

2. 核心思路

Trie是一种数据结构存储有大量公共前缀的字符串。
每个节点维护：

  1. son：指向下一个字符
  2. isEnd：当前节点是否是某个单词结尾

insert(word)：逐字符往下走，不存在就创建，最后把 isEnd 设为 true
search(word)：逐字符查找，最后还要判断 isEnd 是否为 true
startsWith(prefix)：逐字符查找，只要路径存在就返回 true

3. 触发点

看到“多次查询某个单词/前缀是否存在”
看到“很多字符串有公共前缀”
看到“需要动态插入再查询”

4. 易错点

忘记维护isEnd

5. 复杂度

时间：insert/startWith/search都是O(L)L是字符串长度
空间 O(nL) n是单词数量，L是单词最大长度

6. 我的收获

看到前缀查询+多次查找/插入，想到Trie
