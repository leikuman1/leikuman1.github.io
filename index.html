前缀树

题目名：前缀树

1. 题型标签

字符串，前缀，字典树

2. 核心思路

Trie是一种数据结构存储有大量公共前缀的字符串。
每个节点维护：

  1. son：指向下一个字符
  2. isEnd：当前节点是否是某个单词结尾

insert(word)：逐字符往下走，不存在就创建，最后把 isEnd 设为 true
search(word)：逐字符查找，最后还要判断 isEnd 是否为 true
startsWith(prefix)：逐字符查找，只要路径存在就返回 true

3. 触发点

看到“多次查询某个单词/前缀是否存在”
看到“很多字符串有公共前缀”
看到“需要动态插入再查询”

4. 易错点

忘记维护isEnd

5. 复杂度

时间：insert/startWith/search都是O(L)L是字符串长度
空间 O(nL) n是单词数量，L是单词最大长度

6. 我的收获

看到前缀查询+多次查找/插入，想到Trie

sql常用工具

写 SQL 题时，真正高频的工具不多，记住下面几个就够了。

1. 聚合函数

  • COUNT(*)：统计行数
  • SUM(col)：求和
  • AVG(col)：求平均
  • MAX(col) / MIN(col)：最大值 / 最小值

2. CASE WHEN

做条件判断、分类统计时最常用。

3. IFNULL() / COALESCE()

处理空值，避免结果是 NULL。

4. ROW_NUMBER()

分组排名、取每组第一条时非常常见。

小结

刷题时先熟练这 4 个：

  • 聚合函数：做统计
  • CASE WHEN：做条件
  • IFNULL() / COALESCE()：处理空值
  • ROW_NUMBER()：做分组排名
