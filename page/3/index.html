电话号码的字母组合
Hot100 2026/4/23

核心思路

跟前两道回溯题一个套路，就是用递归表示一种更高级的循环(迭代)，
定义结果集ans，暂存变量path来存储答案元素，定义字母表，开头两个空串便于映射
开始递归，如果当前已经走了n步，加入结果集并返回
否则，遍历digits对应的数字对应的字母表，加图path中开启下一轮递归，完成后pop恢复现场

触发点

看到“枚举所有组合”，想到回溯

易错点

忘记恢复现场，导致结果不对
这题要在主函数里判断digits是否为空，空的话直接返回空数组

复杂度

时间 O(n*4^n) n是digits长度，4^n是组合数量，每个组合需要O(n)的时间添加到结果集中
空间 O(n) path的长度为n，递归栈深度也是n

子集
Hot100 2026/4/22

核心思路

枚举子集的第1个数选谁，第2个数选谁……第n个数选谁，

将没选的结果直接加入结果集，再从当前位置开始枚举，枚举结束后恢复现场

触发点

看到“枚举所有子集”或者“需要枚举所有组合”，想到回溯

易错点

忘记恢复现场，导致结果不对

复杂度

时间 O(n*2^n) n是数组长度，2^n是子集数量，每个子集需要O(n)的时间添加到结果集中
空间 O(n) path的长度为n，递归栈深度也是n

我的收获

是否恢复现场与当前状态是否修改共享状态有关，修改了共享状态就要恢复现场，没修改就不需要恢复现场

全排列
Hot100 2026/4/22

核心思路

回溯，维护visited和path，递归中保存递归层数，等于nums大小时添加到结果集中，然后遍历nums，没有被访问的就添加到path中并标记为已访问，
递归下一层，递归下一层结束后标记为未访问，即回溯。

触发点

全排列很容易想到回溯

易错点

忘记回溯，导致结果不对
做递归类题目需要确定什么时候回溯，什么时候不回溯

复杂度

时间 O(n*n!) n是数组长度，n!是全排列数量，每个全排列需要O(n)的时间添加到结果集中
空间 O(n) path的长度为n，递归栈深度也是n
